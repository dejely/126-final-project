Gamemode Scoring Criteria
For all gamemodes, the final score is determined by how many correct guesses a user can make in a row.

### Issue #9
Streak Mechanics
A streak begins when there is no current streak or when the last streak has expired
- The streak is checked whenever a user finishes a game and gets a score higher than 5
- When the date before returns an active streak, add this date to the streak and increment it
- When there is no active streak set on the date before, start a new streak
